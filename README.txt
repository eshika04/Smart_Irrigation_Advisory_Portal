Notes:
1. The gallery uses local SVG images so it works without downloading image files.
2. weather.html embeds IMD and Google Maps using iframes.
3. media.html contains sample remote video/audio URLs. Replace them with your own Smart Irrigation video/audio if your faculty requires agriculture-specific media.
4. All pages contain the same navigation bar and are connected.
5. The CSS requirements from the experiment sheet have been adapted to the Smart Irrigation use case instead of the unrelated "book.html/product card" examples.
